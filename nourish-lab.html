Selected work / Case study

Nourish Lab — a reusable visual system

Two internship tasks: build a three-page website for any niche using components and variants throughout, then restyle it in three different ways. I chose science-led nutrition.

Role
Solo designer
Context
Internship practice tasks, 2026
Tools
Figma (components, variants, variables)
Deliverables
Design system page, three desktop pages, three themed versions
Task one: a system firstTask two: three themesReflection & next steps

Task one: a system first

I defined a palette (Ink, Ivory, Plum, Lime, Mist), a serif and sans pairing, and built navigation states, button variants, a program card and an input as components. The pages were assembled from those pieces so a change in one place carries through the site.

Task two: three themes

I restyled the same pages as Clinical Minimal, Modern Scientific and Vintage Apothecary. Layout and content stayed the same while colour, type and tone changed, which showed how far the same structure can stretch.

Reflection & next steps

  • The hero and cards sit in boxes inside boxes, which feels heavy.
  • The component set is small. It needs a footer, form states and saved text and colour styles.
  • Only desktop layouts exist, so I would add responsive versions.
